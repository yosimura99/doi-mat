# Đổi Mặt

Ứng dụng web (PWA) đổi khuôn mặt giữa hai ảnh hoặc trực tiếp qua camera trước. Mọi xử lý chạy **ngay trên máy** (MediaPipe Face Landmarker + WebGL2), không tải ảnh lên máy chủ.

Mở: https://yosimura99.github.io/doi-mat/ → trên iPhone: Safari › Chia sẻ › Thêm vào MH chính.

Chỉ dùng cho vui. Chỉ dùng ảnh của bạn hoặc người đã đồng ý. Không dùng để giả mạo, lừa đảo hay làm nội dung người lớn.
